Platform berbasis web untuk menyimpan, mengelola, dan berkolaborasi dalam kode program menggunakan sistem Git.
Platform ini didukung oleh berbagai komponen utama seperti repository sebagai tempat penyimpanan proyek, branch untuk membuat cabang kode terpisah agar tidak merusak sistem asli, serta commit sebagai catatan riwayat perubahan. Selain itu, terdapat fitur Pull Request untuk mengajukan dan mendiskusikan penggabungan kode, issues untuk melacak bug atau tugas, serta GitHub Actions untuk mengotomatisasi pengujian aplikasi.
Dalam praktiknya, alur kerja standar atau GitHub Flow dimulai dengan membuat branch baru, menulis dan menyimpan kode melalui commit, membuka Pull Request untuk ditinjau oleh tim, hingga akhirnya melakukan merge untuk menggabungkan kode baru ke branch main jika sudah disetujui.
Untuk menjaga kualitasnya, pembatasan atau proteksi pada branch main sangat penting diterapkan guna mencegah masuknya kode rusak, mewajibkan code review oleh rekan satu tim, serta memastikan semua pengujian otomatis berjalan dengan lancar sebelum sistem diperbarui.
