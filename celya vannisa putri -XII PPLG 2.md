Keuntungan utama dari pembatasan branch main dalam tim pengembang adalah untuk mencegah terjadinya kegagalan sistem operasional atau production crash akibat adanya kode yang belum teruji secara matang. Selain itu, pembatasan ini menjaga keamanan kolaborasi tim sehingga setiap anggota dapat bekerja secara terpisah tanpa risiko merusak atau menimpa kode milik anggota lain, serta memastikan adanya proses kontrol kualitas melalui peninjauan atau code review lewat Pull Request sebelum kode digabungkan.
Seluruh perintah Git yang digunakan mulai dari membuat branch fitur terpisah, menyimpan progres lokal, hingga mengirimkannya ke GitHub dimulai dengan membuat serta berpindah ke branch fitur menggunakan perintah git checkout -b fitur-mfa. Setelah file dikerjakan, progres lokal disimpan ke staging area dengan perintah git add ., dilanjutkan dengan melakukan commit menggunakan pesan terstruktur seperti git commit -m "feat: menambahkan fitur autentikasi multi-faktor (MFA)". Terakhir, branch tersebut dikirimkan ke GitHub agar siap ditinjau lewat Pull Request menggunakan perintah git push -u origin fitur-mfa.
