1. KEUNTUNGAN Pembatasan Branch Main
Keuntungannya adalah menjaga agar kode utama tetap aman dan tidak mudah mengalami kesalahan. Dengan menggunakan branch terpisah setiap anggota bisa mengerjakan fitur masing-masing tanpa mengganggu pekerjaan orang lain. sebelum digabungkan ke branch main, hasil pekerjaan bisa diperiksa terlebih dahulu untuk memastikan tidak ada kesalahan yang dapat mengganggu jalannya website

2. Perintah Git
Berikut perintah Git yang digunakan untuk membuat branch, menyimpan progres, dan mengirimkan hasil pekerjaan ke GitHub.

# Memeriksa perubahan file
git status

# Menambahkan file jawaban ke staging area
git add Siti_Fannia_XII_PPLG_3.md

# Menyimpan perubahan dengan commit
git commit -m "feat: menambahkan jawaban soal KK-2"

# Mengirim branch ke GitHub
git push -u origin jawaban-siti_fannia_xii_pplg_3

Setelah berhasil dikirim ke GitHub, langkah selanjutnya adalah mengajukan Pull Request agar hasil pekerjaan bisa diperiksa oleh guru sebelum digabungkan ke repository utama.
