# Jawaban Version Control

## 1. Keuntungan pembatasan branch main

Keuntungannya supaya branch main tetap aman dan tidak langsung terkena kesalahan dari fitur yang sedang dibuat. Jadi fitur baru bisa dikerjakan di branch sendiri dan diperiksa dulu sebelum masuk ke main.

## 2. Perintah Git

git checkout -b jawaban-desinta_xiipplg2

git add xiipplg2.md

git commit -m "Menambahkan jawaban STS"

git push origin jawaban-desinta_xiipplg2
